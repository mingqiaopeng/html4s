# html4s 能力矩阵：壳版 vs Web 版

同一份 `.html4s`，两种宿主的能力差异一览。分享单文件给讲者时，据此说明哪些功能可用。

| 能力 | 壳版（Html4sPlayer.exe） | Web 版（浏览器打开单文件） |
|---|---|---|
| 放映 / 全屏 | F5 / F11 / 壳无边框全屏 | F5 / 点击按钮（浏览器全屏 API） |
| 浏览模式（缩略图侧栏 + 舞台预览） | ✅ | ✅ |
| 逐页转场 / 碎片 / 自动播放 / 循环 | ✅ | ✅ |
| 总览网格（G）· 黑白屏（B/W）· 激光笔（L） | ✅ | ✅ |
| **演讲者双窗口**（副屏自动放置） | ✅ 壳开第二个窗口 | ❌ 无第二窗口 |
| **演讲者抽屉**（同屏练习模式，S 键） | ✅ | ✅ 承担完整 speaker notes 体验：**备注字号可调（A−/A＋，记忆）**、下一页/下一碎片预览、计时 |
| 排练计时写回 `.timings.json` | ✅ | ❌ |
| 最近打开（Ctrl+R / 标题栏右键） | ✅ | — |
| 打开本地文件 / 网址 | 原生对话框（Ctrl+O / Ctrl+L） | 文件选择器 + prompt 跳转 |
| 深浅色主题（含标题栏联动） | ✅ 标题栏同步 | ✅ 仅页面 UI |
| 深链 `#/n` 直达页 · kiosk | ✅ | ✅（深链） |
| 内嵌字体 / 图标 / 零网络 | ✅ | ✅ |

**结论**：现场正式演出 → 壳版（双窗演讲者 + 写回）；发给别人预演/自用 → Web 版抽屉已够（S 键开抽屉，A−/A＋ 调备注字号）。
